# Release 1.1.0 — Dargent v1.1.0

**Status at authorship (E16 S0):** written pre-tag (runbook §2 item 2). **Cut: 2026-09-08
(annotated tag `v1.1.0` on main).** This release carries the complete **E15 — Operational
Hardening** epic. No API contract changes; no schema changes; no new app env vars beyond the
webhook abuse controls (which ship generous defaults and never affect smoke/demo paths).

## What ships (E15, by step)

- **Webhook abuse controls (S1, DEBT-8 real closure):** in-app `WebhookAbuseControlFilter` on
  `POST /webhooks/psp` — per-IP token-bucket **rate limit → 429** (zero money-path side effects)
  and **body cap → 413** (decided on `Content-Length` before the body/HMAC is consumed; bounded
  read guards chunked/lying headers). New canonical errors `rate_limited` / `payload_too_large`.
  Env-tunable: `DARGENT_WEBHOOK_RATE_LIMIT_CAPACITY` (100), `…_REFILL_PER_SECOND` (0.5),
  `DARGENT_WEBHOOK_BODY_CAP_BYTES` (65536). ITs: `WebhookRateLimitIT`, `WebhookBodyCapIT`;
  10th frozen metric series `dargent_webhook_rejections_total{reason}`.
- **Tested alert rules (S2):** 7 Prometheus rules (`docker/prometheus/rules/alert-rules.yml`)
  with severity labels + runbook anchors, thresholds anchored to `docs/slos.md`; `promtool
  test rules` firing+quiet for EVERY rule, in CI on every push (untested rule = red build;
  bite-proof red run `34228122177` on record).
- **k6 money-path baseline (S3):** published number — **414 rps / 59 620 requests at 24 VUs,
  0.00% error rate**, p95 create 17.08 ms / replay 3.04 ms / pay 1.0 ms / confirm 2.58 ms
  (`docs/load-test-baseline.md`, consultative — not a CI gate).
- **Restore at production-like scale (S4):** dispatch-only `restore-drill-scale` job —
  SQL bulk-seed of 50 000 txns / 150 000 postings mirroring the real posting shape, then the full
  backup → destroy → restore → verify drill. **Measured RTO 23 s** at 5.6 MB dump, run
  `34244399134`; drill record `docs/drills/restore-scale-2026-09-08.md` with the three-point
  delta (36 KB→~20 s · 2.28 MB→21 s · 5.6 MB→23 s — RTO flat).
- **PITR rehearsal (S5):** standalone harness (`scripts/pitr-rehearsal.sh`) — archive_mode →
  base backup → post-base side effects → **kill -9** → WAL replay to `recovery_target_lsn`,
  paused and validated at the recovered state (counts + ΣDR=ΣCR + projection==lines). **Measured
  RPO ≈ 6 s** (`docs/drills/pitr-2026-09-08.md`); three PG16/docker gotchas documented; AGENTS
  amendment (f) born (research before trial-and-error).
- **DEBT-7 Path A (S6):** `postJournal`/`postJournalWithoutBalances` twins consolidated behind
  `postJournalCore(entry, updateBalances)` — payment path posts with balances, refund path keeps
  the E8 conditional drain owning them atomically. Full suite green; floors PASS; E8/E9 guarantee
  ITs re-evidenced (RefundRaceIT 2/2, RefundBalanceGuardIT 2/2, RefundFlowIT 2/2,
  Scenario20NoDoubleJournalIT 1/1, JournalCoverageAuditorIT 6/6, JournalBalanceDbBarrierIT 4/4).
- **Governance:** demo overlay (`docker/compose.demo.yaml`, spine ON) + BLOCK 1 audit record
  (`docs/audit-e15-block1.md`); evidence-lint scanned-id count 105 at epic start.
